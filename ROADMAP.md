# Engineering sequence

Goal: choose, construct, measure and deploy local model configurations under explicit quality and hardware constraints. Preserve each producer's native protocol, license and release history. No universal model score.

| Gate | Deliverable | Exit test |
| --- | --- | --- |
| G1 | Content-addressed artifact registry | Renamed byte-identical files share identity; changed bytes do not; no stale path is accepted as proof. |
| G2 | Frozen experiment contract | Bind inputs and declared execution settings before inference; reject modified inputs or plan; separate planned from observed evidence. |
| G3 | Managed runtime | Exclusive cooperative GPU lease, free-memory preflight, owned loopback server, template/health probe, bounded startup and owned-process cleanup. |
| G4 | Unified inference | Typed request and response, strict usage and termination, raw payloads, ordered frozen schedule, resumable run, duplicate protection; no implicit retries that change denominators. |
| G5 | Versioned adapters | Reproduce native TrustMeBro and BudgetFit scoring from frozen responses. ConceptLadder is an upstream versioned generator, not a second score for shared tasks. Preserve Q4Fit and QuantBench native evidence; keep incompatible licenses in their own packages. |
| G6 | Evidence and cache | Join on exact artifact identity; reuse only exact compatible execution, input and scorer contracts. Historical unbound evidence stays unbound. |
| G7 | Optimization | First optimize one axis at a time (runtime, budget, quantization), then a bounded joint Pareto search on accuracy, fidelity, latency, memory and bytes. Freeze policies before held-out verification. Reject failed or under-supported candidates. |
| G8 | Model Passport | Path-free export with artifact hashes, evidence links, settings, status, uncertainty and missing dimensions. Never infer a missing metric. |
| G9 | Product | One local CLI and end-to-end clean-machine smoke test; release only tested adapters. |

G1/G2 prototype limits: local Linux; single-file little-endian GGUF header checks, not full tensor/metadata verification. Standard shard filenames are rejected; arbitrary renamed split artifacts are not detected. Registry paths and spec files are private local state. Contract identity is a hash, not a signature or proof of runtime behavior. The template probe is a frozen rendered example, not a complete standalone template fingerprint; embedded template bytes are covered by the GGUF hash. Runtime dependencies must be explicitly enumerated where needed; a binary hash alone is not a complete runtime fingerprint. File hashes are checked before and after managed execution in G3, not proof against transient hostile replacement.

Integration order: first establish a new bound run through the existing BudgetFit/TrustMeBro stack; then add Q4Fit and QuantBench through their native adapters; then llama-autotune and EXL3. No changes to published repositories until an adapter passes its parity tests. No new GPU experiment merely to test schema, cache or report code. No automatic model publishing or deletion.

## Gate progress

- G1/G2: initial registry and frozen contract implemented; real Q2 artifact and runtime fingerprints matched the previous reference records; planned input integrity verified.
- G3: managed single-GPU Linux/NVIDIA smoke path implemented. Real Qwen3.8-27B Q2_K: frozen template probe matched; literal completion passed; server exited normally; GPU memory 16 → 10602 → 16 MiB. The initial live run covered the runtime lifecycle; the additional sampling allowlist is tested separately.
- G4 next: separate the runtime session from its smoke workload, freeze an explicit request schedule (prompt, settings, task ID), write ordered raw response records atomically, support resume only after rechecking contract and backend, and preserve errors separately. Reuse the evaluator's prompt and scoring interfaces rather than inventing a second benchmark.
- G4: frozen request schedule, ordered managed inference, strict response accounting, atomic per-batch checkpoints and resume implemented. Real Q2 test completed 3+5 unique requests in two sessions; a third invocation issued zero new requests. Nineteen automated tests passed. Automatic retry of an uncommitted session is intentionally blocked; explicit crash recovery remains open.
- G5 next: bind the native evaluator executable and protocol to task/prompt pairs; validate schedule generation against the evaluator; re-score stored responses without GPU and compare with native result semantics. Start with the pinned BudgetFit/TrustMeBro engine and keep all diagnostic axes independent.
- G5 initial adapter: pinned BudgetFit/TrustMeBro/ConceptLadder stack integrated, including exact native prompt preparation, preflight validation, offline grading, separate track/family/level and recovery reports. Eight real G4 replies scored; historical parity passed 1,824/1,824 on all checked fields. Twenty-two tests passed including native archive integration. G5 remains open for additional adapter types, custom data, and adaptive validation.
- G6 next: register complete evaluation reports against sealed source sessions, keep source and derived evidence identities distinct, implement conservative exact-contract replay. Before adding cache hits, bind the evaluator/report schema and observed runtime evidence; never reuse historical unbound reports as deployment evidence.
- G6 core: content-addressed SQLite source/derived evidence store, exact contract and artifact indexes, native regrading on ingestion and explicit historical replay. Duplicate ingestion is idempotent; corrupt blobs, index mismatches, report disagreements and ambiguous source selection fail closed. 28 tests passed. Cross-contract response caching remains disabled because runtime dependency identity and independent replicate semantics are not complete.
- G7 next: first add a read-only constrained candidate selector using comparable evidence; require explicitly declared objective, quality floor, matching task matrix and runtime context. Separate exploratory selection from independently validated deployment. Do not combine fidelity and task metrics into a single arbitrary score. Then connect native BudgetFit search/held-out validation, followed by runtime and quantization candidate adapters.
- G7 initial: constrained fixed-configuration selector, Pareto frontier, immutable decision with validation seed and single-holdout paired acceptance gate. Thirty-six tests passed. Real 16-request Q2 calibration rejected 256/allocated/64 against 1024/allocated/64: 44.26% lower mean completion tokens but 62.5% versus 75% joint accuracy, below the 73% floor. No holdout run or deployment policy was produced. Positive and negative held-out branches exercised with synthetic tests only. Next: integrate the native BudgetFit adaptive router with bound managed evidence; then runtime and weight candidate adapters, including measured memory and compatible paired task evidence.

- G7-B Adaptive Router: implemented pinned native training, sparse paired schedule validation, frozen decision/seed/thresholds, managed holdout, evidence ingestion and exact-contract replay integration. Historical parity matched 820/820 stored Q2/Q4 requests and original pass/fail outcomes. Reused the existing 16-request seed 609 calibration; froze the 95-byte native policy before independent seed 610. Thirteen new requests completed in one sealed session. Router achieved 87.5% joint accuracy versus fixed 75%, but consumed 4.13% more mean completion tokens; native gate correctly failed. The failure remains archived; no deployment policy or replacement holdout. Thirty-nine automated tests passed. Next: G7-C Runtime Optimization, followed by G7-D Weight Optimization, G7-E constrained joint optimization, G8 Model Passport and G9 release.

- G7-C initial runtime adapter: integrated local llama-autotune v0.1.8 native capability discovery, bounded candidate generation and argument rendering with existing managed inference. Added linked dependency hashes, observed mapped-library identity, NVML v2 repeated memory sampling and separate native prefill/decode metrics. Seed 611 paired f16/q8_0 pilot completed 16 new requests; both candidates eligible and Pareto-nondominated. Q8_0 sampled peak was 108 MiB lower, with marginally lower throughput. All 23 observed mapped libraries per run were frozen. Forty-three automated tests passed. Context-frontier, independent runtime holdout, general candidate grids, multi-GPU placement and exact allocator peaks remain open. Next: G7-D native weight and fidelity evidence integration; do not repeat the completed runtime pilot.

- G7-D initial weight adapter: native QuantBench compact-statistics and bootstrap parity, release-manifest and native validation-log verification, Q4Fit native depth-export replay and actual source/candidate GGUF hash verification for recipe evidence. Eight indexed records, six unique candidates, two reference identities. Exact artifact join exposes missing axes instead of inferring matching names; no managed accuracy overlap with current weight cohorts. One-cohort constrained KL/size Pareto selection implemented. Fifty automated tests passed. Full logit regeneration, prospective quantization search and cross-axis paired evidence remain open. Next G7-E: constrained joint selection with explicit missing-metric rejection, matched execution evidence, and independent validation; no repeated prior experiments.

- G7-E initial joint selector: exact matched managed task/runtime cohort, optional named fidelity cohort (required for cross-weight comparisons), hard constraints on accuracy/latency/tokens/sampled memory/headroom/file size/KL, Pareto front, frozen objective and independent paired holdout contract/path binding. Strict fidelity policy correctly returns no eligible candidates because historical weight and managed runtime cohorts do not intersect. Same-artifact runtime-only policy selects Q8_0 KV. Fifty-eight automated tests passed. Adaptive routing in joint search, actual cross-weight measurements and large independent validation remain open. G8 next: portable model passport with explicit missing axes and validation status.

- G7-E seed-612 independent pilot completed: 16 requests archived, frozen Q8_0 challenger rejected on truncation and holdout reference-accuracy drop despite saving 108 MiB sampled VRAM. No rerun or threshold adjustment. Joint selection remains an engineering prototype, not a certified optimizer.

- G8 initial Model Passport: deterministic versioned portable JSON envelope, exact artifact and reference identities, independent weight and managed task evidence, diagnostic breakdowns, runtime input hashes, observed flags, sampled memory/throughput, selection decisions, failed holdouts and explicit missing axes. Offline expected-digest verification, optional actual GGUF hash check and exact current local snapshot comparison. Seven real passports exported and verified against local evidence, 65 automated tests passed. Not digitally signed, not a self-contained raw evidence replay package, not a deployment certificate. Next G9: package CLI, install/doctor workflow and end-to-end safe local release.

- G9 local alpha: Python wheel and isolated CLI launcher, explicit optional NumPy/NVML dependencies, read-only doctor, Python 3.12 and 3.13 clean virtual-environment install tests. Engine source bytes preserved, no models/state/native producer archives bundled. Installed CLI exercised registration, portable passport, offline model-identity verification and native schedule generation. This is a private local release candidate, not a published distribution or an end-to-end GPU test on another machine. Remaining adapters and cross-weight measurement gaps are explicitly open.
